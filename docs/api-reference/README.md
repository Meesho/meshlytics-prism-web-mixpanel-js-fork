# API Reference

`mixpanel-browser` is a client-side JavaScript browser analytics library — a Meesho fork of the
[Mixpanel JS SDK](https://github.com/mixpanel/mixpanel-js). It exposes no HTTP API endpoints and
is consumed via npm, not via HTTP calls.

No per-endpoint `flow.md` files are generated here because there are no HTTP operations in
`schemas/openapi.yml`. See the library's public surface in [`src/`](../../src/) instead.

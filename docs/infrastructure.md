# Infrastructure

`mixpanel-browser` is a published npm package — there is no deployed infrastructure
(no servers, no containers, no databases).

## Artifact Registry

The package is distributed via Meesho's internal GCP Artifact Registry.
Registered in Ringmaster under `repo_type: library` with `publish_node_package` enabled.

| Property | Value |
|----------|-------|
| Package name | `mixpanel-browser` |
| GCP project | `meesho-devops-admin-0622` |
| `repo_type` | `library` |
